	ErrBondLockNotFound = errors.New("bond: lock not found")

	ErrBondExtendFailed = errors.New("bond: failed to extend lock")

type BondManager struct {
	// Has unexported fields.
}
    Mutexes are stored by key so ReleaseLock and ExtendLock can target the same
    instance. The global mu protects the entries map only — it is never held
    during Redis I/O.

func (r *BondManager) AcquireLock(ctx context.Context, key string, ttl time.Duration) (bool, error)
    The lock expires automatically; call ReleaseLock to release it early.

func (r *BondManager) ExtendLock(ctx context.Context, key string, ttl time.Duration) error

func (r *BondManager) ReleaseLock(ctx context.Context, key string) error
    ReleaseLock uses the stored mutex instance for a clean unlock. If the lock
    has already expired or was never acquired, returns nil.

type IdempotencyStore struct {
	// Has unexported fields.
}
    IdempotencyStore implements eywa.IdempotencyStore using Redis SETNX. The
    first Seen call for a key sets it with the given TTL and reports false (not
    a duplicate); subsequent calls within the TTL window find the key present
    and report true.

func (s *IdempotencyStore) Seen(ctx context.Context, key string, ttl time.Duration) (bool, error)
    Seen records key via SETNX with ttl and reports whether it was already
    present. SetNX returns true when the key was set (first occurrence),
    so a duplicate is the inverse.

type InboxManager struct {
	// Has unexported fields.
}
    InboxManager implements eywa.Inbox using Redis lists. Messages are appended
    via RPUSH with a sliding TTL. PopAll reads and deletes the list atomically
    in a single pipeline to avoid partial reads.

func (r *InboxManager) PopAll(ctx context.Context, memoryKey string) ([]string, error)
    PopAll atomically reads all messages and deletes the inbox key. Returns an
    empty slice when the inbox is empty or the key does not exist.

func (r *InboxManager) Push(ctx context.Context, memoryKey string, message string) error
    Push appends message to the memory inbox and refreshes the TTL.
