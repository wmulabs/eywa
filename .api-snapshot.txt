package eywa // import "github.com/wmulabs/eywa"

Package eywa is a Go library for building event-driven, multi-agent AI systems.

Inspired by the neural network in Avatar that connects all living things on
Pandora, Eywa orchestrates a network of AI Spirits (agents) that perceive Pulses
(events), are enriched by Scouts, routed by a Pathfinder, consult an Oracle
(LLM), execute Actions (tools), and respond through a Voice (output channel).

Pipeline:

    Pulse → Scouts → Pathfinder → Spirit → Oracle → Actions → Voice

The central runtime is the Weave, assembled via NewWeaveBuilder. It wires
together repositories (Spirit, Memory, Echo, Chronicle), a Bond (distributed
lock), one or more Oracle providers, and optional registries for Actions,
Scouts, Pathfinders, and Voices.

Quick start:

    weave, err := eywa.NewWeaveBuilder(ctx).
        WithRepositories(spiritRepo, memoryRepo, echoRepo, chronicleRepo).
        WithBond(distributedLock).
        AddOracle(anthropicOracle).
        Build()

See the _examples directory for runnable examples.

    OracleFactoryImpl is the concrete Oracle factory. Register providers via
    RegisterProvider, then pass it to WeaveBuilder.WithOracleFactory.

type OracleMessage = ports.OracleMessage
    OracleMessage is a single message in the conversation thread sent to an
    Oracle.

type OracleRequest = ports.OracleRequest
    OracleRequest is the input sent to an Oracle. It carries the conversation
    thread, available tools, attachments, and generation parameters.

type OracleResponse = ports.OracleResponse
    OracleResponse is the output returned by an Oracle after one generation
    step.

type OracleTool = ports.OracleTool
    OracleTool describes a tool (Action) schema as sent to the Oracle provider.

type OracleToolCall = ports.OracleToolCall
    OracleToolCall is a tool invocation requested by the Oracle in its response.

type OracleUsage = ports.OracleUsage
    OracleUsage records token consumption for a single Oracle call.

type OrchestratorConfig = entities.OrchestratorConfig
    OrchestratorConfig configures a SpiritTypeOrchestrator. SubSpirits lists the
    names the orchestrator may summon; MaxDepth caps delegation chains.

type Pathfinder = ports.Pathfinder
    Pathfinder is the Spirit-selection port. Implement it for custom routing
    logic. Register via PathfinderRegistry.Register.

type PathfinderRegistry = ports.PathfinderRegistry
    PathfinderRegistry holds the set of Pathfinders available to the Weave
    engine.

type ProgressPolicy = orchestrator.ProgressPolicy
    ProgressPolicy configures reasoning-loop stall detection. Set on
    WeaveBuilder.WithProgressPolicy.

type PubSub = ports.PubSub
    PubSub is the publish/subscribe port used by ConfigCache for live-update
    notifications when event configurations change.

type Pulse = entities.Pulse
    Pulse is the unit of work flowing through the Weave — an inbound
    event from any channel. Build one with NewPulse and send it via
    Weave.ProcessEventByKey.

type PulseBuilder = entities.PulseBuilder
    PulseBuilder constructs a Pulse with a fluent API. Obtain one via NewPulse.

type Receptor = ports.Receptor
    Receptor converts a raw inbound payload (webhook body, queue message) into a
    Pulse. Register via Weave.RegisterReceptor.

type RecurrenceConfig = entities.RecurrenceConfig
    RecurrenceConfig defines cron-based recurrence for a Ritual (timezone,
    expression, max runs, end date).

type ReflectionPolicy = orchestrator.ReflectionPolicy
    ReflectionPolicy configures the pre-delivery self-critique pass. Set on
    WeaveBuilder.WithReflectionPolicy.

type Response = entities.Response
    Response is the result returned by Weave.ProcessEventByKey. It contains the
    assistant message, which Spirit was used, Actions executed, and token usage.

type ResponseStatus = entities.ResponseStatus
    ResponseStatus classifies the outcome of a Weave processing call.

type Rite = entities.Rite
    Rite is an async approval request created by the request_rite built-in
    action. An operator approves or rejects it via RiteRepository.Decide or the
    management API.

type RiteListOptions = ports.RiteListOptions
    RiteListOptions filters a Rite query by status, Spirit, or user.

type RiteRepository = ports.RiteRepository
    RiteRepository persists Rite (async approval) records.

type RiteStatus = entities.RiteStatus
    RiteStatus is the lifecycle state of a Rite.

type Ritual = entities.Ritual
    Ritual is a scheduled or recurring event managed by the Keeper. Created
    by the schedule_ritual built-in action; delivered back as a Pulse at the
    scheduled time.

type RitualManager = ports.RitualManager
    RitualManager coordinates Ritual lifecycle: create, list, cancel, and fire
    scheduled events. Create with NewRitualService.

type RitualRepository = ports.RitualRepository
    RitualRepository persists Ritual definitions and tracks their execution
    state.

type RitualRequest = ports.RitualRequest
    RitualRequest is the input for scheduling a new Ritual.

type RitualStatus = entities.RitualStatus
    RitualStatus is the lifecycle state of a Ritual.

type Scorer = ports.Scorer
    Scorer evaluates a single TrialCase response. Implement for custom eval
    metrics. Built-in scorers: NewOutputContainsScorer, NewActionSequenceScorer,
    NewLLMJudgeScorer.

type Scout = ports.Scout
    Scout is the context-enrichment port. Implement it to inject knowledge into
    a Pulse before Spirit selection. Register via ScoutRegistry.Register.

type ScoutRegistry = ports.ScoutRegistry
    ScoutRegistry holds the set of Scouts available to the Weave engine.
    Create with NewScoutRegistry; pass via WeaveBuilder.WithScoutRegistry.

type SessionListOptions = ports.SessionListOptions
    SessionListOptions filters a conversation session query.

type SessionSummary = ports.SessionSummary
    SessionSummary is a lightweight summary of a conversation session for
    listing.

type Spirit = entities.Spirit
    Spirit is an AI assistant definition stored in the SpiritRepository.
    It carries the system prompt, model configuration, and the list of Actions
    the Oracle may invoke. Spirits are versioned — every update creates a new
    version, allowing rollback.

type SpiritModel = entities.SpiritModel
    SpiritModel specifies which Oracle provider and model a Spirit uses,
    along with generation parameters (Temperature, MaxTokens, TopP).

type SpiritRepository = ports.SpiritRepository
    SpiritRepository persists Spirit definitions.

type SpiritStats = ports.SpiritStats
    SpiritStats aggregates per-Spirit usage metrics.

type SpiritType = entities.SpiritType
    SpiritType controls which built-in capabilities a Spirit has. Defaults to
    SpiritTypeConversational.

type SubjectKey = entities.SubjectKey
    SubjectKey identifies the business entity being discussed in a conversation
    (e.g. an order ID or ticket number). Set by the update_subject built-in
    action.

type TemplateComponent = ports.TemplateComponent
    TemplateComponent is a section of a WhatsApp template message.

type TemplateMessage = ports.TemplateMessage
    TemplateMessage is a WhatsApp template message with its components.

type TemplateParameter = ports.TemplateParameter
    TemplateParameter is a single variable parameter within a WhatsApp template.

type Thread = entities.Thread
    Thread is the ordered list of messages in the current conversation window.
    When the window fills, the Archivist summarises older messages.

type TokenBudget = entities.TokenBudget
    TokenBudget sets a monthly token limit for a Spirit with configurable
    enforcement: "block" (reject when exceeded), "downgrade" (switch to a
    cheaper model), or "alert".

type TokenSeries = ports.TokenSeries
    TokenSeries is a time-bucketed token usage series returned by analytics
    queries.

type TokenValidator = ports.TokenValidator
    TokenValidator authenticates inbound API requests. Implementations include
    NewAPIKeyValidator, NewJWTValidator, and NewJWKSValidator.

type ToolResultLimits = ports.ToolResultLimits
    ToolResultLimits bounds how much a single Action result contributes to the
    reasoning context. Pass via WeaveBuilder.WithToolResultLimits.

type ToolResultShaper = ports.ToolResultShaper
    ToolResultShaper is an optional interface an Action may implement to
    override the global ToolResultLimits for its own results.

type ToolShapeStrategy = ports.ToolShapeStrategy
    ToolShapeStrategy selects how an oversized Action result is reduced
    (truncate or summarize).

type TrialCase = entities.TrialCase
    TrialCase is a single eval test case with input, context, and scoring
    expectations.

type TrialExpectations = entities.TrialExpectations
    TrialExpectations declares what a TrialCase response must satisfy to pass.

type TrialReport = entities.TrialReport
    TrialReport aggregates TrialResults from a full TrialSuite run.

type TrialResult = entities.TrialResult
    TrialResult holds the outcome of a single TrialCase execution.

type TrialRunner = trial.TrialRunner
    TrialRunner executes eval suites against a live Weave, scoring responses
    with deterministic and LLM-as-judge Scorers.

type TrialSuite = entities.TrialSuite
    TrialSuite is a collection of TrialCases loaded from YAML or JSON via
    LoadTrialSuite.

type TypingIndicator = ports.TypingIndicator
    TypingIndicator sends a typing-in-progress signal on a channel while the
    Oracle reasons.

type Vault = ports.Vault
    Vault is the object storage port for media files (images, audio, documents).
    Use the GCS adapter for Google Cloud Storage.

type Vigil = entities.Vigil
    Vigil represents an operator's active seat on a conversation. While a Vigil
    seat is held, the Weave returns ErrSessionHeld and the operator handles
    messages directly.

type VigilConfig = orchestrator.VigilConfig
    VigilConfig controls human-takeover behaviour. InactivityTimeout sets how
    long an operator seat stays active without activity before auto-releasing.

type VigilRepository = ports.VigilRepository
    VigilRepository persists active Vigil seats (operator takeover state) in
    Redis.

type Voice = ports.Voice
    Voice delivers a Spirit's response to an external channel (WhatsApp, HTTP,
    etc.). Register via VoiceRegistry.Register.

type VoiceRegistry = ports.VoiceRegistry
    VoiceRegistry holds the set of Voices available to the Weave engine.
    Create with NewVoiceRegistry; pass via WeaveBuilder.WithVoiceRegistry.

type Weave = orchestrator.Weave
    Weave is the central runtime engine. Assemble it via NewWeaveBuilder,
    then call ProcessEventByKey to handle Pulses. A single Weave instance is
    safe for concurrent use.

type WeaveBuilder = orchestrator.WeaveBuilder
    WeaveBuilder assembles a Weave via a fluent API. Obtain one with
    NewWeaveBuilder, chain With*/Add*/Register* methods, and call Build to
    produce the Weave.

type WeaveConfig = orchestrator.WeaveConfig
    WeaveConfig holds global engine settings (timeouts, iteration limits, etc.).
    Use DefaultWeaveConfig for sensible defaults, then override individual
    fields.

type WeaveConfigRepository = orchestrator.WeaveConfigRepository
    WeaveConfigRepository persists WeaveConfig to a durable store (e.g.
    MongoDB). Used by the management API to support hot-reload.

type WhatsAppClient = ports.WhatsAppClient
    WhatsAppClient sends WhatsApp messages and templates via a provider's API.
